# GUIDE to Hugo commands

Краткий справочник команд для текущего проекта BWWH.

## 1. Проверить версии инструментов

```bash
mise current
```

Показывает версии инструментов из `mise.toml`.

В текущем проекте:

```toml
[tools]
hugo = "latest"
node = "24"
python = "3.14"
```

## 2. Запустить сайт локально

```bash
hugo server -D
```

Что делает команда:

- запускает локальный сервер Hugo;
- показывает draft-страницы, если они есть;
- автоматически пересобирает сайт после сохранения файлов.

Обычный адрес:

```text
http://localhost:1313/
```

## 3. Собрать сайт

```bash
hugo
```

Что делает команда:

- читает `hugo.yaml`;
- берет контент из `content/` и `themes/basic/content/`;
- применяет шаблоны из `themes/basic/layouts/`;
- создает готовый сайт в `public/`.

## 4. Собрать сайт как для GitHub Pages

```bash
hugo --minify --baseURL "https://sock-puppet-dev.github.io/BWWH/"
```

Что добавляют параметры:

- `--minify` уменьшает итоговые HTML/CSS/JS-файлы;
- `--baseURL` задает правильный адрес опубликованного сайта.

## 5. Очистить старые файлы сборки

```bash
hugo --cleanDestinationDir
```

Используй, если в `public/` могли остаться старые файлы после удаления страниц.

Вариант с минификацией:

```bash
hugo --cleanDestinationDir --minify
```

## 6. Создать новую страницу

```bash
hugo new about/index.md
```

Создает leaf bundle:

```text
content/about/index.md
```

Такой формат удобен, если рядом со страницей позже нужны изображения или другие файлы.

## 7. Создать новый учебный пост

```bash
hugo new posts/my-first-post.md
```

Для текущего проекта важно понимать разницу:

- основные страницы лежат в `content/`;
- учебные посты сейчас лежат в `themes/basic/content/posts/`;
- Hugo публикует оба источника.

## 8. Создать новую тему

```bash
hugo new theme basic
```

Эта команда уже использовалась для создания локальной темы `themes/basic`.

Повторно запускать ее в текущем проекте не нужно, иначе можно перезаписать учебную тему.

## 9. Проверить состояние Git

```bash
git status --short
```

Если вывод пустой, рабочее дерево чистое.

## 10. Отправить изменения на GitHub

```bash
git add .
git commit -m "Описание изменения"
git push origin main
```

После `git push` GitHub Actions автоматически запустит деплой.
